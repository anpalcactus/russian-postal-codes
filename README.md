# Почтовые индексы России — открытые данные

Полная выгрузка почтовых индексов России: **61 362 индексов** объектов
почтовой связи, 29 167 населённых пунктов, 1 832 районов,
86 регионов и **1 630 389 адресных записей** — улицы и группы домов с
привязкой к индексу.

Данные собраны из официальных источников и обновляются вслед за ними: релиз
справочника Почты выходит раз в две недели, выгрузка пересобирается за ним
автоматически. Текущий релиз — **2026-08-11**.

Сайт-справочник на этих же данных: **<https://pochtovyindex.ru>**
Страница любого индекса: `https://pochtovyindex.ru/index/<шесть цифр>/`

### indexes.csv

| Поле | Описание |
| --- | --- |
| `index` | почтовый индекс, шесть цифр |
| `name` | наименование объекта почтовой связи |
| `type_code` | код типа из справочника: `О`, `П`, `ПОЧТОМАТ`, `МСЦ`, `ТИ`, `ДТИ` и другие |
| `type_name` | расшифровка типа, если она однозначна; иначе повторяет код |
| `addressable` | `1` — индекс используется в почтовом адресе, `0` — технический |
| `parent_index` | индекс вышестоящего объекта (почтамта, сортировочного центра) |
| `region`, `area`, `city` | регион, район, населённый пункт |
| `settlement` | подчинённый населённый пункт, который обслуживает отделение |
| `act_date` | дата, с которой действует запись |
| `url` | страница индекса на сайте |

**Про `addressable`.** Половина путаницы с индексами — из-за технических
записей: сортировочные центры, участки, склады, дополнительные технические
индексы. В адресе они не используются, письмо с таким индексом не дойдёт.
В официальной выгрузке они лежат вперемешку с обычными отделениями, здесь
помечены явно: адресных объектов 39 526 из 61 362.

### streets.csv.gz

| Поле | Описание |
| --- | --- |
| `index` | почтовый индекс |
| `address` | адресный объект: «ул. Ленина», «пер. Суворовский 11-й» |
| `houses` | номера домов, если этот индекс относится не ко всей улице, а к части |

Пустое поле `houses` означает, что индекс относится ко всей улице. Это тот
случай, который обычно теряют: в одном городе у разных домов на одной улице
индексы разные.

## Быстрый старт

```bash
# индекс по адресу
zcat data/streets.csv.gz | grep -i "ул. Ленина" | head

# все отделения Курской области, только адресные
awk -F, '$7=="Курская область" && $5==1' data/indexes.csv | wc -l
```

```python
import pandas as pd

idx = pd.read_csv("data/indexes.csv", dtype={"index": str, "parent_index": str})
addressable = idx[idx.addressable == 1]
print(len(addressable), "адресных индексов")

# сколько индексов в городе
print(addressable[addressable.city == "Курск"][["index", "name"]])
```

## Как обновляется

Справочник Почты выходит раз в две недели. Сборка ежедневно проверяет номер
релиза и пересобирает выгрузку только когда он сменился — здесь всегда
актуальная версия, а не срез годичной давности.

## Нашли ошибку

Данные не редактируются вручную: если запись неточна в справочнике Почты, она
такой и приедет сюда — переписывать официальный источник по своему усмотрению
для справочника недопустимо. Но об ошибке разбора обязательно напишите:
issue в этом репозитории или info@pochtovyindex.ru. Проверим по первоисточнику
и, если ошибка наша, поправим.
